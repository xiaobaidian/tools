# A4 图片排版工具（紧凑填满版）

本地运行的单文件网页工具：把多张图片紧凑排进 A4（300DPI）版面，可直接打印 / 下载 PNG。

## 特点
- **紧凑填满**：不再用固定网格 + 居中留白。改为「行式填充」——每一行的图片等比缩放，使该行宽度刚好铺满整页可用宽度（横向 100% 填满）；纵向按最优行数自动撑到接近整页高度。
- **自适应分页**：图片很多时自动拆成多页，每页都尽量填满；单张大图会最大化居中（不裁切）。
- **可调留白**：支持设置「边缘留白」与「图片间距」（单位 mm），留白越小越满。
- **零依赖 / 离线**：纯前端，图片不上传，本地浏览器处理，保护隐私。

## 用法
1. 用浏览器打开 `index.html`（或经门户进入）。
2. 点击 / 拖拽上传图片（支持 JPG、PNG、BMP 等）。
3. 按需调整「边缘留白」「图片间距」。
4. 点「生成 A4 排版」→ 逐页预览，可单页下载或一键下载全部。

## 排版算法简述
- 每张图按宽高比 `r = w/h` 参与布局。
- 一行图片统一缩放使行宽 = 可用宽：`行高 = (可用宽 - 间距×(n-1)) / Σr`，因此横向始终铺满。
- 遍历候选行数 `R`，取「能放进单页且总高最大」的方案 → 纵向也尽量满。
- 一行放不下时换行；整页放不下时进入下一页（分页）。
