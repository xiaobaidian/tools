# 🖼️ A4 图片排版工具

把多张图片自动排版到 A4 纸上，生成 **300DPI** 高清图，方便打印或导出 PDF。纯前端、无需上传服务器，本地浏览器即可运行。

## 功能
- 拖拽 / 多选上传多张图片
- 自动按 A4（横向/纵向可选）排版，保持比例
- 一键生成 300DPI 的整页图片
- 支持预览、单张移除、清空重来、下载结果

## 用法
直接用浏览器打开 `index.html` 即可（也已在门户挂载，点「打开」）。
1. 点按钮添加图片
2. 调整排版参数（如方向）
3. 生成 → 下载 / 打印

## 依赖
- 零依赖，纯 HTML + Canvas，离线可用
- 注意：图片在本地处理，**不会上传任何服务器**
