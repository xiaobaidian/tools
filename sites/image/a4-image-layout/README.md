# A4 图片拼贴工具（紧凑单页版）

把所有图片浓缩到 **一张 A4**（300 DPI），用 treemap 紧凑拼贴，最大化利用纸张空间。

## 功能
- **单页输出**：无论多少张图，全部排进同一张 A4，不分页
- **紧凑拼贴**：treemap 面积二分 + 切向择优，整页被图片 100% 覆盖（仅留极小边缘）
- **不变形**：每张图等比缩放（contain），不裁切、不拉伸
- **可调**：边缘留白、图片间距（mm）；间距 = 0 时图片之间无缝相接
- **本地处理**：纯浏览器运行，零上传、零依赖、离线可用
- **导出**：生成 PNG，单张下载或一键保存

## 用法
1. 打开页面（门户 → 图片工具 → A4 图片拼贴）
2. 点击或拖拽上传图片
3. 调好「边缘留白 / 图片间距」
4. 点「生成 A4 排版」→ 预览 → 下载

## 技术
- 纯前端单文件 HTML，无外部 CDN / 字体依赖
- 布局算法：递归面积二分 treemap（按原始像素面积降序切分，切向选更接近正方形的方向），整页归一化铺满；每图在所属矩形内 contain 居中
- 画布 2480×3508（A4 @300DPI），导出 PNG
