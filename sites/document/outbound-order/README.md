# 📄 出库单生成器

上传 Excel 或粘贴数据源，自动解析记录并生成规范 **出库单**（含单号、合计数量 / 金额），支持打印、复制到剪贴板、导出 PDF。医疗 / 耗材 / 仓储场景适用。纯前端，数据本地处理不上传。

## 功能
- 上传 `.xlsx` / 粘贴表格数据，自动解析记录（序列号、品名、厂家、型号、效期等）
- 按关键词自动简化品名 / 厂家 / 型号，生成整洁出库单
- 自动计算合计数量、合计金额，生成连续单号
- 一键打印、复制为文本、导出 PDF

## 用法
浏览器打开 `index.html`（门户点「打开」）。
1. 选「选择文件」导入 Excel，或直接粘贴数据源
2. 点「解析 / 生成出库单」
3. 打印或导出

## 依赖
- 解析 Excel 用本地内置的 `xlsx.full.min.js`（已随仓库提供，**无需联网**）
- 纯前端，数据不出本机

## 文件
- `index.html`：工具本体
- `xlsx.full.min.js`：SheetJS 库（本地化，离线可用）
