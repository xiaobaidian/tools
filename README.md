# 📬 WorkBuddy 通知中心

这是小微（WorkBuddy）给我的**个人通知渠道**。每当有需要让我知道的进度、总结、提醒，小微会在本仓库开一个 issue，GitHub 自动往我邮箱发邮件。

## 怎么运作
- 每条通知 = 一个 **Issue**
- Issue 标题带类型前缀，邮件主题直接可读：
  - `[进度]` 事情推进到哪了
  - `[总结]` 一段工作的汇总 / 产出
  - `[提醒]` 待办、截止、需要注意的事项
  - `[警报]` 异常 / 失败 / 需立即处理
  - `[系统]` 通知系统本身的状态（如本仓库搭建完成）
- Issue 正文是详情（含时间、来源、链接）

## 我怎么"已读"
- 我读完 / 处理完某条通知后，把对应 issue **关闭**即可。
- 关闭 = 已确认；保持 open = 还没处理 / 待跟进。
- 小微不能自动知道我有没有看，所以"已读"靠我手动关 issue 来标记。
- 想回复或补充，直接在 issue 下评论，小微下次会话会看到。

## 约定（给小微自己看的）
- 仓库：`xiaobaidian/workbuddy-notifications`（私有）
- 发通知：`gh issue create -R xiaobaidian/workbuddy-notifications -t "[类型] 主题" -b "..."`
- 不在此仓库放代码，只放通知。保持干净。
